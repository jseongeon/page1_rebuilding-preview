§02

현장 이야기

현장에서는 아직도
이런 일이 반복됩니다

담당자의 꼼꼼함만으로는 한계가 있습니다. 현장이 말하는 세 가지 불편입니다.

  1. Situation 01“기록이 여러 곳에 흩어져 있어요.”종이·엑셀·메일에 흩어진 기록은 누락과 버전 오류를 만듭니다.
  2. Situation 02“실사 다가오면 야근이 늘어나요.”자료를 다시 찾고 대조하느라 실사 대응은 매번 사람에게 의존합니다.
  3. Situation 03“시스템마다 정보가 달라요.”문서·교육·품질·시험이 분리되면 변경과 이력의 추적성이 끊깁니다.

BQUBE가 답합니다

  • 기록은 한 곳에문서·교육·품질 기록을 BQUBE 하나에서 관리합니다. 로그인 한 번, 권한 설정 한 번입니다.
  • 실사 자료는 바로 조회통합 Audit Trail에서 변경 이력과 근거를 바로 찾습니다.
  • 변경은 자동으로 연결SOP 승인 → 교육 배정 → 품질 연계까지 전 프로세스가 자동으로 흘러갑니다.

이 문제는 개인의 주의만으로 해결되지 않습니다. 규정 준수와 데이터 무결성을 시스템으로 관리해야 합니다.

GxP 통합 플랫폼 - 하나의 BQUBE로 EDMS·QMS·LMS 통합 관리

§07

BQUBE 플랫폼

BQUBE는 문서(EDMS)·품질(QMS)·교육(LMS) 세 시스템을 하나로 묶은 GxP 통합 플랫폼입니다. 세 시스템이 BQUBE CORE로 연계되어 승인된 SOP가 품질 프로세스와 교육 과정으로 자동 흐르고, 모든 활동이 단일 대시보드와 Audit Trail에서 통합 관리됩니다. 이중 입력 없이 Data Integrity를 보장하며, 자체 기술력 기반으로 연 2~3회 업데이트와 연동비용 무상을 제공합니다.

현장의 문제

  • 각 시스템을 따로 운영하여 데이터 연계가 안 되고 이중 작업 발생
  • 외산 S/W 도입 시 높은 비용과 맞춤화 어려움

해결 방식

  • BQUBE CORE - EDMS·QMS·LMS를 하나의 플랫폼에서 통합 관리
  • 단일 대시보드·Audit Trail로 문서·품질·교육 전 활동 통합 추적
  • 자체 기술력 기반 - 현장 담당자가 직접 설계 참여
  • 연 2~3회 S/W 업데이트 + CSV 변경관리 함께 제공, ERP·타 시스템 연동비용 무상

전자문서관리 시스템 - BQUBE CORE 통합 관리

§08

BQUBE-EDMS

GxP 문서를 생성부터 폐기까지 전체 Life-Cycle에 걸쳐 일관성 있게 통합 관리하는 시스템입니다. SOP, 제품표준서, 기록서 및 Validation 문서까지의 전체적인 GxP 문서 관리를 제공하며, BQUBE CORE로 QMS·LMS와 연계되어 승인된 문서가 품질 프로세스·교육 과정으로 자동 흐릅니다.

현장의 문제

  • 종이 문서 관리로 분실/훼손 위험, 검색 불가
  • 문서 결재/배포/회수가 수기여서 버전 관리 어려움

해결 방식

  • BQUBE CORE 통합 - 승인 문서가 QMS 품질 프로세스·LMS 교육으로 자동 연계
  • GMP 문서 Life Cycle 통합 관리 - 버전 통합 관리
  • MS-Office 기반 편리한 작성 및 검토, 문서 비교 기능
  • 출력 횟수/권한 관리, 문서결재/검토 특인 알람

BQUBE-QMS

품질관리 시스템 - BQUBE CORE 통합 관리

§09

BQUBE-QMS

GMP 전반에 대한 품질관리를 전산화한 시스템으로, 제조 및 품질의 문제요소를 실시간 조치하고 교육 및 모니터링을 통해 일탈에 대한 사전 예방 및 관리 기능을 제공합니다. 프로세스 빌더와 디자인 편집기로 일탈·변경·CAPA 등 품질 프로세스를 직접 설계하며, BQUBE CORE로 EDMS 문서·LMS 교육 이력과 하나의 추적선으로 연결됩니다.

현장의 문제

  • 품질 이벤트(일탈/변경/CAPA)를 수기로 관리하여 추적 어려움
  • FDA/EMA 실사 시 문서 보존성 및 보안 문제

해결 방식

  • BQUBE CORE 통합 - 품질 이벤트가 EDMS 문서·LMS 교육 이력과 단일 추적선으로 연결
  • 프로세스 빌더·디자인 편집기로 품질 프로세스 직접 설계·자동화
  • 품질 데이터 실시간 조회로 신속한 의사결정, Data Integrity 이슈 원천 제거
  • FDA/EMA 실사 대응력 강화 - 문서 보존성 및 보안

BQUBE-LMS

교육관리 시스템 - BQUBE CORE 통합 관리

§10

BQUBE-LMS

교육 준비에서부터 진행, 완료까지 전반적인 교육을 관리하기 위한 솔루션입니다. 교육 진행 상태 실시간 모니터링이 가능하며, 전자결재를 통한 이력 관리를 제공합니다. BQUBE CORE로 EDMS·QMS와 연계되어 SOP가 개정되면 해당 교육 대상과 이력에 자동 반영되고, 직무분석표 기반으로 필요한 교육을 배정합니다.

현장의 문제

  • 교육 결과를 수기 기록하여 Data Integrity 확보 어려움
  • 반복적인 교육에 대한 공수 부담, 빠른 실사 대응 불가

해결 방식

  • BQUBE CORE 통합 - EDMS 문서 개정 시 교육 대상·이력에 자동 반영
  • 직무분석표 기반 교육 배정, 다국어 지원
  • 모든 Data 및 이력에 대한 Paperless - GMP 규정 준수
  • Audit Trail·Data Integrity 준수, 교육 진행 상태 실시간 모니터링

EBR

SAP 기준정보 수신 → 전자 제조지시서(레시피) 작성 → MBR 결재·시행 → 현장 생산 실행 → 배치기록서(PDF) 발행까지 제조 기록의 전 주기를 하나의 시스템에서 관리합니다. 지시서에 정의한 변수가 그대로 현장 입력 항목이 되고 그 값이 그대로 배치기록서 출력이 되어, 옮겨 적는 구간과 전사 오류가 사라집니다.

현장의 문제

  • 배치기록서가 종이로 회람되어 검토·발행에 며칠이 걸리고, 빈칸·오기·후기입을 사람이 반복 확인
  • Word·Excel 제조지시서(MBR)의 버전·시행일을 사람이 관리해 구버전이 현장에 남을 위험

해결 방식

  • 지시서 변수 = 현장 입력 = 배치기록서 출력 - 단일 데이터로 전사 오류 원천 제거
  • 승인 전 시뮬레이션으로 지시서 오류를 현장이 아닌 사무실에서 사전 검증
  • 승인·시행 이중 상태 관리 - 시행일 자동 전환, 구버전 자동 만료로 이중 사용 차단
  • 작업자격 연계 전자서명 및 결재선 스냅샷 - 자격 없는 서명 차단, 실사 시 당시 결재경로 재현
  • SAP 생산오더·기준정보 append-only 수신, MES·LIMS·QMS·EDMS·WMS REST API 연동
  • FDA 21 CFR Part 11·EU Annex 11·PIC/S·KGMP·ALCOA+·GAMP 5 준거 - Audit Trail 자동 기록

§20

자주 묻는 질문

더 궁금하신 점은 아래 도입문의로 남겨 주세요.

도입까지 얼마나 걸리나요?

솔루션에 따라 6개월~1년이 걸리며, QMS는 약 1년이 필요합니다.

EDMS·QMS·LMS를 한 번에 도입해야 하나요?

하나부터 시작할 수 있습니다. 추가 솔루션 도입 시 기존 BQUBE 환경에서 메뉴만 확장하면 됩니다.

기존 MES·ERP를 교체해야 하나요?

교체하지 않아도 됩니다. MES·LIMS·ERP·e-HR·DRM·POP와 API 기반으로 연동하며, 기존 시스템 교체 없이 확장합니다.

On-Premise 구축도 가능한가요?

SaaS 구독형과 On-Premise 구축형 모두 가능합니다. DRM 등 사내 보안 정책과도 연동합니다.

CSV는 별도 업체에 맡겨야 하나요?

BQUBE를 개발한 조직의 자체 CSV팀이 GAMP 5 기반으로 IQ·OQ·PQ 전 단계를 직접 수행합니다. 업데이트에 따른 변경관리 CSV도 함께 제공합니다.

EDMS에 PDF도 올릴 수 있나요?

일반 파일로 업로드 가능합니다(Word·Excel·PPT 포함).

검토자 한 명이 반려하면 바로 반려되나요?

바로 반려되지 않고, 전원 검토가 끝난 뒤 상신자에게 반려됩니다.
